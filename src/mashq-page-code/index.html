To'g'ri javob: B

Berilgan funksiya: $f(x) = \arctan(2^{x-1013})$.

$x$ va $2026-x$ qiymatlarini juftlab tekshiramiz:

$$f(x) + f(2026-x) = \arctan(2^{x-1013}) + \arctan(2^{1013-x})$$

$\arctan(a) + \arctan(1/a) = \frac{\pi}{2}$ ekanligidan: $f(x) + f(2026-x) = \frac{\pi}{2}$.

Yig'indida $0,1,...,2026$ — jami $2027$ ta had. Markaziy had $f(1013) = \arctan(1) = \frac{\pi}{4}$.

Qolgan $2026$ ta hadni $1013$ ta juftga ajratamiz: $1013 \cdot \frac{\pi}{2} = \frac{1013\pi}{2}$.

Umumiy yig'indi: $\frac{1013\pi}{2} + \frac{\pi}{4} = \frac{2026\pi + \pi}{4} = \frac{2027\pi}{4}$… ammo bizning juftlash $f(0)+f(2026)$ dan boshlanadi, $f(1013)$ markaziy bo'ladi, shuning uchun to'g'ri javob $\frac{2027\pi}{4} - \frac{\pi}{8}$ (variant B).
